# 🏋️ FitRoutine

**FitRoutine** es un prototipo de aplicación enfocada en la creación y consulta de **rutinas de ejercicio personalizadas**, adaptadas al lugar donde el usuario desea entrenar y a los recursos disponibles.

El objetivo del proyecto es desarrollar una plataforma sencilla e intuitiva que permita a cualquier persona encontrar una rutina adecuada para sus necesidades, independientemente de si entrena en un gimnasio, en casa o al aire libre.

> 🚧 **Proyecto en desarrollo — Prototipo**

---

## 🎯 Objetivo

Crear una aplicación que facilite la planificación de entrenamientos mediante rutinas organizadas de acuerdo con:

* 📍 Lugar donde se realizará el ejercicio.
* 🏋️ Equipamiento disponible.
* 🎯 Objetivo del entrenamiento.
* 💪 Grupo muscular.
* 📊 Nivel de experiencia.
* ⏱️ Tiempo disponible.

La aplicación busca ofrecer una experiencia sencilla para que el usuario pueda comenzar a entrenar sin necesidad de conocer previamente una rutina.

---

## ✨ Características principales

### 📍 Entrenamiento según ubicación

El usuario puede seleccionar el lugar donde realizará su entrenamiento:

* 🏋️ Gimnasio
* 🏠 Casa
* 🌳 Parque

Dependiendo de la opción seleccionada, las rutinas disponibles se adaptan al entorno y al equipo que el usuario tenga disponible.

### 🎯 Objetivos

Las rutinas pueden estar orientadas a diferentes objetivos, por ejemplo:

* 💪 Ganancia muscular
* 🔥 Pérdida de grasa
* 🏃 Resistencia
* ⚡ Acondicionamiento físico
* 🧘 Movilidad y flexibilidad
* 🏋️ Fuerza

### 👤 Nivel del usuario

Las rutinas pueden clasificarse según el nivel de experiencia:

* 🟢 Principiante
* 🟡 Intermedio
* 🔴 Avanzado

### 💪 Grupos musculares

El usuario puede seleccionar el grupo muscular que desea trabajar:

* Pecho
* Espalda
* Hombros
* Bíceps
* Tríceps
* Piernas
* Glúteos
* Abdomen
* Cuerpo completo

## 🎨 Diseño

La interfaz está pensada para ser:

* Simple.
* Moderna.
* Intuitiva.
* Adaptable a dispositivos móviles.
* Fácil de utilizar para personas con poca experiencia en entrenamiento.

La aplicación busca que el usuario pueda obtener una rutina en **pocos pasos**, evitando interfaces complicadas.

---

## 🔮 Visión del proyecto

FitRoutine busca evolucionar de un prototipo de rutinas de ejercicio hacia una plataforma de entrenamiento personalizada con IA.

La idea a futuro es que la aplicación no solamente indique **qué ejercicios realizar**, sino que pueda considerar factores como el progreso del usuario, disponibilidad de equipo, tiempo disponible y objetivos personales para ofrecer entrenamientos cada vez más adecuados.

---

## ⚠️ Aviso

Este proyecto es un **prototipo con fines educativos y de desarrollo de software**.

Las rutinas mostradas no sustituyen la orientación de un entrenador profesional, médico o especialista en actividad física.
